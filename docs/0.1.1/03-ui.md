# 0.1.1 界面与联网状态

> 状态：已实现
> 0.1.0 的双 panel、Compose、自动/手动选中保持不变
> 关联：[01-scope.md](01-scope.md) · [02-network.md](02-network.md)

## 1. 设计原则

- **不破坏 0.1.0**：双 panel、输入栈、自动/手动选中、`y/Y`、`Q` 退出保持原样。
- **网络状态可见**：在线人数、连接状态、重连结果在状态 panel 可读。
- **消息同列表**：远端消息与本地消息使用同一格式、同一历史、同一选中规则。
- **手动模式不被打断**：用户在看历史时，远端新消息不自动跳；状态提示有新消息。
- **不靠颜色单独表达**：`●`/`◌`/`!` + 文字。
- **文件共享入口不出现**。

## 2. 状态 panel

0.1.0：

```text
在线 1（本机） · 消息 3 · 选中 3/3 · 自动
```

0.1.1 显示：

```text
在线 3 · 消息 12 · 选中 12/12 · 自动 · ● online
```

| 字段 | 说明 |
| --- | --- |
| `在线 N` | N = 本机 + Online peers；不写“含本机”，成员面板标注 `(you)` |
| `消息 N` | 列表消息数（本地 + 远端） |
| `选中 i/N` | 当前选中位置；无消息 `-/-` |
| `自动` / `手动` | 0.1.0 的选择模式 |
| 连接状态 | `● online` / `◌ connecting` / `◌ reconnecting` / `! offline` |
| 临时提示 | `已发送` / `复制成功` / `复制失败` / `重连中` / `有新消息` |
| Compose | `输入中 · Enter 发送 · Esc 取消 · 消息 N` |

宽度紧张时：

- 优先保留 `在线 N`、`消息 N`、`选中`、连接状态；
- 在线数始终含本机；成员面板标注 `(you)`；
- 临时提示可覆盖连接状态 2 秒，随后恢复。

## 3. 连接状态

| 状态 | 显示 | 时机 |
| --- | --- | --- |
| 无网络配置 | `local` / 无连接符号 | 0.1.1 仍允许完全本地使用 |
| 连接中 | `◌ connecting` | TCP connect / handshake |
| 在线 | `● online` | 至少一个 peer Ready；或全部已知 peer 在线 |
| 重连中 | `◌ reconnecting` | 有 peer 断开且自动重连开启 |
| 离线 | `! offline` | 手动断开或全部失败 |

- 0.1.1 不弹出模态连接框；错误进状态/toast。
- 启动时如果 mDNS 不可用：状态提示 `自动发现不可用，使用 --connect 手动连接`。
- 协议不兼容/重复 node_id：状态显示可读错误，不崩溃。

## 4. 远端消息与选中

### 4.1 自动模式

- 收到远端消息：追加列表，选中最新，滚到底。
- 与 0.1.0 本地发送一致。
- 状态可短暂显示 `已接收` 或直接更新消息数。

### 4.2 手动模式

- 用户 `j/k` 选中非最新后进入手动模式。
- 收到远端消息：**不改变选中/滚动**。
- 状态 panel 追加 `有新消息`，直到用户回到最新或按 `G`/`j` 到最后。
- 用户 `j` 到最新后恢复自动模式；随后新消息继续自动跟随。

> 这条规则与 0.1.0 完全一致；0.1.1 只是把“新消息”的来源扩展到网络。

### 4.3 Compose 期间收到远端消息

- 消息仍进入列表；选中高亮隐藏。
- 不弹出、不打断输入。
- 输入 panel 关闭后：
  - 自动模式：选中最新（含期间收到的消息）；
  - 手动模式：保持打开输入前的选中，状态提示有新消息。
- 发送消息时仍按 0.1.0 规则：自动模式选新消息，手动模式保持原选中。

## 5. 成员面板（已确认）

作为**新的 Layer**，右侧侧边栏，不破坏 `Vec<Layer>`：

```text
┌ 信息列表 ───────────────────────────────┬ 成员 ──────────────┐
│ [alice][2026-11-19 10:30]: 你好         │ ● alice (you)      │
│ [bob][2026-11-19 10:31]: 在             │ ● bob 192.168.1.23 │
│                                          │ ◌ carol connecting │
├──────────────────────────────────────────┴─────────────────────┤
│ > i 开始输入                                                    │
├─────────────────────────────────────────────────────────────────┤
│ 在线 3 · 消息 2 · 选中 2/2 · 自动 · ● online                  │
└─────────────────────────────────────────────────────────────────┘
```

- 打开：List 层 `Space u`；再次 `Space u` 关闭；`Esc` 也关闭。
- 选中：`j/k` 上下选择成员；`Esc` 关闭；`Q` 仍退出。
- 内容：昵称、`(you)`、地址、连接状态。
- 0.1.1 不做私聊；`Enter` 不绑定或只查看详情。
- 成员侧边栏只占右侧宽度（建议 24–30 列），消息列表仍可见；Compose 下不响应 `Space u`。

## 6. 系统加入/离开

两个选项：

| 方案 | 行为 | 影响 |
| --- | --- | --- |
| A（推荐） | 状态/toast：`bob 加入` / `bob 离开` | 不改变消息列表/选中；简单 |
| B | 插入列表的 system 消息 | 需要 `kind: system`、选中规则、历史格式；可能打断手动模式 |

**已确认 A**。0.1.0 的消息格式 `[name][datetime]: message` 保持不变；系统事件不混入聊天记录。未来若需要系统消息，再引入 `kind`。

## 7. 错误与提示

- 发送失败：消息保留，状态 `! 发送失败: ...`；不静默丢。
- 无在线 peer：本地消息仍显示；状态 `无在线节点`。
- 协议错误：状态 `! 协议错误: ...`；关闭该连接。
- 重复 node_id：`! node_id 冲突`。
- 重连：状态 `◌ reconnecting`；成功后 `● online`。
- 日志不含消息正文；状态/toast 不显示堆栈。

## 8. 键位增量

0.1.0 默认：

- List：`i/j/k/y/Y/Q`
- Compose：`Enter/Esc`
- 保留：`Q`、Compose Enter/Esc

0.1.1 已确认新增（可配置）：

| 键 | action | 说明 |
| --- | --- | --- |
| `Space u` | `toggle_users` | 打开/关闭成员面板 |
| `Space r` | `reconnect` | 重连全部 |
| `Space d` | `disconnect` | 手动断开（可选） |

- Compose 下仍只认 Enter/Esc 应用快捷键；`Space u`/`Space r`/`Space d` 不触发。
- 成员面板打开时，`Space u`/`Esc` 关闭；`j/k` 遍历成员。
- `Q` 退出保持。

## 9. 本地无网络回退

- 没有 peer / mDNS 失败：界面与 0.1.0 一致；状态显示 `在线 1` 或 `local`。
- 网络错误不阻塞输入/历史/复制。
- 不显示文件共享入口。

## 10. 已确认

- 成员面板：右侧侧边栏，`Space u` 开关，`j/k` 选择，`Esc` 关闭。
- 在线人数：只写 `在线 N`，N 含本机；成员面板标注 `(you)`。
- 加入/离开：状态/toast，不插入列表。
- 远端消息时间：本地接收时间。
- 手动模式：新消息不跳；状态提示有新消息。
- 重连/断开：`Space r` / `Space d`；`--no-network` 回退本地。

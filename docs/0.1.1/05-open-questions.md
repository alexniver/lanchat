## 已确认的交互约束

1. 0.1.0 的自动/手动选中语义不变。
2. 远端新消息在手动模式下不自动跳；状态提示有新消息。
3. Compose 下仍只认 Enter/Esc 应用快捷键。
4. `Q` 退出保持。
5. `Space u` 只在 List 层打开成员侧边栏；Compose 下不响应。
6. 成员侧边栏是右侧侧边栏，不替换消息列表；再次 `Space u` 关闭。
7. 文件共享入口不出现。
8. 日志不记正文；历史 `0600`。

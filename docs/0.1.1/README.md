# lanchat 0.1.1 联网需求讨论

> 状态：**0.1.1 核心已实现，验收中**（0.1.0 已冻结）
> 基线：0.1.0 单机版已实现并通过验收
> 建立日期：2026-11-19
> 版本：0.1.1（验收中）

## 一句话目标

在 0.1.0 的双 panel、输入栈、自动/手动选中、JSONL 历史、可配置 keymap 基础上，加入**同局域网文本聊天**：自动发现、单房间群聊、心跳/重连；不引入文件共享。

## 0.1.0 基线（冻结）

0.1.0 已实现并验收：

- 上下双 panel：信息列表 + 3 行状态。
- `[name][datetime]: message`。
- `i` 打开 Compose；Enter 发送、Esc/空 Enter 取消；`Esc`/`Enter` pop 层栈。
- List 自动/手动选中；`j/k` 切换；手动下新消息不自动跳。
- `y` 复制正文、`Y` 复制完整行。
- `Q` 退出；Compose 下只认 Enter/Esc 应用快捷键。
- JSONL 历史、可配置 `keymap.toml`、CJK 宽度、终端恢复。

**0.1.1 不修改这些交互语义**；只在其上增加网络来源的消息、在线状态和重连等能力。已有 0.1.0 测试作为回归基线。

## 讨论流程

1. 未定项写入 [05-open-questions.md](05-open-questions.md)，每项给选项和推荐。
2. 确认后写入 [decisions.md](decisions.md)，并同步修改 scope/UI/network/architecture。
3. 网络协议先单测，再接 App/UI；避免网络问题掩盖本地 UI 回归。
4. 0.1.1 发布前必须跑通 0.1.0 的全部本地测试与核心验收。

## 术语

| 术语 | 含义 |
| --- | --- |
| 节点 / peer | 运行 lanchat 的一个实例 |

| 手动模式 | 用户选中非最新消息；新消息不自动跳 |

# 0.1.5 已确认决策

## D-034 使用 node_id，不用 IP 最后一段

- **状态**：已确认（2026-11-19）
- **决策**：用户显示名追加 node_id 短标识；移除 IP 最后一段方案。
- **理由**：node_id 稳定、唯一；IP 会变、可能重复、IPv6 无末位。

## D-035 显示格式 `基础名 (node8)`

- **状态**：已确认
- **决策**：`alice@arch (19b9b31e)`；短标识为 node_id 前 8 个字符。
- **影响**：完整 node_id 仍可用于命令；成员栏可读。

## D-036 不修改 identity/协议

- **状态**：已确认
- **决策**：`identity.name`、`Hello.name`、`Chat.name` 保持基础名；只组合显示名。
- **影响**：0.1.4 兼容；配置不被污染。

## D-037 历史保存显示名

- **状态**：已确认
- **决策**：`Message.name` 保存组合名；旧历史不变。
- **影响**：重启后旧消息保留当时的 node8。

## D-038 文件传递支持 node_id

- **状态**：已确认
- **决策**：
  - `/send file <路径> to <node_id>`；
  - `/recv file <node_id>`；
  - 支持完整 node_id 和唯一前缀；
  - 保留完整 IP/昵称便利寻址；
  - 不再支持 IP 最后一段。
- **影响**：文件提示使用 `/recv file <node8>`。

## D-039 空名/已有后缀

- **状态**：已确认
- **决策**：空基础名显示 `用户 (node8)`；已有 ` (8位hex)` 替换为当前 node8。
- **影响**：不出现双后缀/孤立后缀。

## D-040 版本 0.1.5

- **状态**：已确认
- **决策**：本功能作为 0.1.5；保持 0.1.4 聊天/文件/帮助/路径行为。
- **影响**：Cargo/CLI/README/帮助版本更新。

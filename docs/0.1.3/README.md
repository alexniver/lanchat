# lanchat 0.1.3 帮助页面需求讨论

> 状态：**0.1.3 已实现，验收中**（0.1.2 已冻结）
> 版本：0.1.3
> 建立日期：2026-11-19

## 一句话目标

在消息列表（info panel）按 `?` 打开一个全屏帮助页面：

- 上方是帮助内容，可滚动；
- 下方保留 3 行状态栏；
- `j` / `k` 上下滚动；
- `Esc` 退出帮助，回到原来的消息列表。

帮助页面只读，不修改消息、不发送内容、不触发网络操作。

## 界面示意

```text
┌ 帮助 ──────────────────────────────────────────────────────────┐
│ LanChat 0.1.3                                                  │
│                                                                │
│ 快速开始                                                       │
│   i        输入消息                                            │
│   /        命令输入（/send file、/recv file）                  │
│   ?        打开帮助                                            │
│   j / k    选择消息 / 在帮助页滚动                             │
│                                                                │
│ 消息列表                                                       │
│   ...                                                          │
│                                                                │
│                                                                │
└────────────────────────────────────────────────────────────────┘
┌ 状态 ──────────────────────────────────────────────────────────┐
│ 按 Esc 退出帮助 · j/k 滚动 · 帮助 1/3 · 在线 2                 │
└─────────────────────────────────────────────────────────────────┘
```

- 帮助面板占据消息列表的位置，右侧不显示成员侧边栏。
- 状态栏仍是底部 3 行。
- 内容超出可视高度时，`j/k` 滚动，状态栏显示当前位置。

## 范围速览

| 能力 | 0.1.3 | 说明 |
| --- | --- | --- |
| List 层按 `?` 打开帮助 | ✅ 做 | 只在消息列表层生效 |
| 帮助内容全屏显示 | ✅ 做 | 上方帮助面板 + 下方状态栏 |
| `j` / `k` 滚动 | ✅ 做 | 行级滚动，边界钳制 |
| `Esc` 退出帮助 | ✅ 做 | 回到 List，选中状态不变 |
| 状态栏提示 | ✅ 做 | `按 Esc 退出帮助` + 滚动位置/在线数 |
| 动态键位提示 | ✅ 建议 | 显示用户当前 keymap，而不是只写默认键 |
| 帮助内容分节 | ✅ 做 | 快速开始、消息、文件、成员、配置等 |
| 鼠标滚动 | ❌ 不做 | 键盘优先 |
| 搜索帮助 | ❌ 不做 | 0.1.3 只滚动 |
| 从 Compose 打开帮助 | ❌ 不做 | Compose 下 `?` 是普通文字 |
| 从帮助里发送/执行命令 | ❌ 不做 | 帮助只读 |
| 帮助内容持久化 | ❌ 不做 | 内存中的静态内容 |
| 帮助页面历史 | ❌ 不做 | 无历史/返回栈 |

## 与 0.1.2 的关系

- 0.1.2 的聊天、文件传递、成员侧边栏、自动/手动选中、历史、网络保持不变。
- 帮助页面是**新的顶层 Layer**，覆盖 List 的显示区域，但不销毁 List 状态。
- 帮助不写入历史，不改变消息列表选中位置，不触发网络请求。
- `?` 是 List 层的新 action；Compose 的 `?` 仍是文本。

## 术语

| 术语 | 含义 |
| --- | --- |
| info panel / List | 当前显示消息列表的层 |
| 帮助页 / Help | 0.1.3 新增的只读帮助 Layer |
| 滚动位置 | 帮助内容首行在完整内容中的行号 |
| 状态栏 | 底部 3 行状态/提示区域 |
| List 选中 | 当前消息列表选中的消息；帮助期间不改变 |

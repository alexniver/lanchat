# 0.1.3 已确认决策

> 只记录已经明确同意的决策；未定项见 [05-open-questions.md](05-open-questions.md)。

## D-016 新增只读帮助页面

- **状态**：已确认（2026-11-19）
- **决策**：0.1.3 增加帮助 Layer，用于在 TUI 内查看使用说明；帮助只读，不发送消息、不执行命令、不修改历史。
- **影响**：帮助内容编译进二进制，不依赖外部文件。

## D-017 List 层按 `?` 打开帮助

- **状态**：已确认
- **决策**：在消息列表（info panel）按 `?` 进入帮助；Compose 下 `?` 是普通字符；Members 下按 `?` 的行为待定（OQ-13-03）。
- **影响**：新增 `ActionId::OpenHelp`；默认绑定 `?`。

## D-018 帮助布局

- **状态**：已确认
- **决策**：上方帮助 panel，显示帮助内容；下方保留 3 行状态栏。
- **影响**：帮助 panel 使用 List 的主区域全宽显示，不显示成员侧边栏/Compose。

## D-019 `j/k` 滚动、`Esc` 退出

- **状态**：已确认
- **决策**：帮助内 `j` 向下、`k` 向上滚动；`Esc` 退出帮助并回到 List。
- **影响**：Help 自己处理按键，不进入 List 的 action 分发。

## D-020 状态栏提示

- **状态**：已确认
- **决策**：帮助状态栏至少包含“按 Esc 退出帮助”；并显示滚动位置和其他辅助信息。
- **影响**：状态栏固定 3 行；极窄时优先保留退出提示。

## D-021 不改变 List 状态

- **状态**：已确认
- **决策**：打开/滚动/关闭帮助不改变 List 的 selected、follow_latest、unread；帮助期间收到的消息正常进入 List。
- **影响**：HelpState 只保存 offset；关闭时只 pop Layer。

## D-022 `?` 可重映射，默认 `?`

- **状态**：已确认（2026-11-19）
- **决策**：`OpenHelp` 作为 action 可配置，默认绑定 `?`。
- **影响**：keymap 可以改键/解绑；帮助内 `?` 不嵌套。

## D-023 Help 内按 `Q` 忽略

- **状态**：已确认
- **决策**：帮助内只有 `Esc` 退出；`Q` 不退出程序、不关闭帮助。
- **影响**：避免只读页误触退出。

## D-024 Members 内按 `?` 忽略

- **状态**：已确认
- **决策**：帮助只从 List 进入；Members 下 `?` 无动作。
- **影响**：不新增层叠行为。

## D-025 Help 的 j/k 固定

- **状态**：已确认
- **决策**：Help 内固定 `j/k` 滚动 + `Esc` 退出，不跟随 CursorDown/CursorUp 的 keymap。
- **影响**：帮助页是键位映射的明确例外；状态栏写 `j/k 滚动`。

## D-026 状态栏显示版本，不显示在线数

- **状态**：已确认
- **决策**：帮助状态栏显示 `按 Esc 退出帮助`、`j/k 滚动`、滚动位置和 `LanChat 0.1.3`；不显示在线人数。
- **影响**：极窄时优先保留 Esc 提示。

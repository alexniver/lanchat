# 帮助页面 UI

> 状态：已实现
> 关联：[01-scope.md](01-scope.md) · [03-content.md](03-content.md) · [04-architecture.md](04-architecture.md)

## 1. 布局

帮助是顶层 Layer，占用 List 的整个主区域：

```text
┌ 帮助 ──────────────────────────────────────────────────────────┐
│ LanChat 0.1.3                                                  │
│                                                                │
│ 快速开始                                                       │
│   i        输入消息                                            │
│   /        命令输入                                            │
│   ?        打开帮助                                            │
│   Esc      退出/取消                                           │
│   Q        退出程序（仅 List）                                  │
│                                                                │
│ 消息列表                                                       │
│   j / k    下/上选择消息                                       │
│   y / Y    复制正文/完整行                                     │
│   Space u  成员侧边栏                                          │
│                                                                │
│ ... 更多内容 ...                                               │
└────────────────────────────────────────────────────────────────┘
┌ 状态 ──────────────────────────────────────────────────────────┐
│ 按 Esc 退出帮助 · j/k 滚动 · 帮助 1/24 · LanChat 0.1.3 · 在线 2 │
└────────────────────────────────────────────────────────────────┘
```

### 尺寸规则

- 状态栏固定 3 行（与 List 一致）。
- 帮助 panel 高度 = `area.height - 3`。
- 帮助 panel 宽度 = 终端宽度（不显示成员侧边栏）。
- 最小终端：沿用 60×15；小于时显示“终端太小”提示。
- 帮助 panel 边框标题：` 帮助 `。

## 2. Layer 行为

```text
List（栈底）
  └─ Help（栈顶，打开）
```

- `?` 在 List 时 push `Layer::Help(HelpState)`。
- `Esc` 在 Help 时 pop。
- List 保留在栈底，其 selected / follow_latest 不变。
- Help 打开时：
  - 不渲染 List 的消息行、选中高亮；
  - 不渲染 Compose；
  - 不渲染成员侧边栏；
  - 只渲染 Help panel + 状态栏。
- Help 关闭后：
  - 顶层回到 List；
  - 选中/自动模式保持；
  - 帮助期间收到的消息已经在 List 中；
  - 若帮助期间进入手动模式？Help 不改变 selected/follow，所以不会。

## 3. 帮助内容渲染

- 内容按行组成，行内文本按终端显示宽度换行（复用 `ui::text::wrap_text` 或类似逻辑）。
- 中文/emoji 使用 `unicode-width`，与消息列表一致。
- 标题行可加样式（粗体/主题色），不加交互链接。
- 帮助内容不进入 `messages`，不参与选中/复制。
- 滚动单位是“渲染后的行”，不是源文本的行；长段落换行后按渲染行滚动。
- 内容不足一屏时：`max_offset = 0`，状态栏显示 `帮助 1/1` 或 `全部显示`。
- 状态栏滚动位置可用：
  - `帮助 12/80`（当前首行/总行数）；或
  - `滚动 15%`。
  - 推荐显示“首行/总行数”，用户更清楚边界。

## 4. 状态栏

### 4.1 基本内容

```text
按 Esc 退出帮助 · j/k 滚动 · 帮助 1/24 · LanChat 0.1.3 · 在线 2
```

各部分：

| 部分 | 说明 |
| --- | --- |
| `按 Esc 退出帮助` | 必须，明确退出方式 |
| `j/k 滚动` | 必须/推荐 |
| `帮助 1/24` | 滚动位置 |
| `LanChat 0.1.3` | 版本 |
| `在线 2` | 可选；网络事件仍更新 |

### 4.2 极窄时

- 状态栏文本截断，但“按 Esc 退出帮助”优先保留。
- 不换行到第二行（状态栏固定 3 行，内容一行 + 边框）。
- 如果宽度不够，优先省略版本/在线数，保留退出提示和滚动提示。

### 4.3 与 List 状态栏差异

- List：在线、消息、选中、模式、连接状态、临时 status。
- Help：退出提示、滚动提示、位置、版本、在线数。
- Help 不使用 List 的临时 status；打开帮助时清掉 List 的临时提示，退出后不恢复（或恢复，见 OQ）。

## 5. 滚动行为

- `j`：offset + 1，最大 `max_offset`。
- `k`：offset - 1，最小 0。
- 每次按键立即重绘。
- 按住/重复按键不加速；按系统 repeat 即可。
- `Home`/`End`/`PgUp`/`PgDn` 可选（P1）。
- 退出再进入默认回到顶部（OQ-13-06）。
- 终端 resize：
  - 重新计算换行和 `max_offset`；
  - 当前 offset 钳制到新范围；
  - 不 panic。
- 帮助打开时后台消息仍进入 List，但不改变 Help offset。

## 6. 键位边界

| 层 | `?` | `j/k` | `Esc` | `Q` |
| --- | --- | --- | --- | --- |
| List | 打开帮助 | 选择消息 | 清除 pending | 退出程序 |
| Help | 忽略 | 滚动帮助 | 退出帮助 | 建议忽略（OQ-13-02） |
| Compose | 输入 `?` | 输入 `j/k` | 取消输入 | 输入 `Q` |
| Members | 忽略（OQ-13-03） | 选择成员 | 关闭成员栏 | 退出程序 |

- Help 不响应 `i`、`/`、`y`、`Y`、`Space u` 等 List action。
- Help 内 `?` 不再嵌套打开帮助。
- Help 内 `Ctrl+C` 不清屏、不退出；可忽略。

## 7. 空/短内容

- 帮助内容始终非空（至少标题 + 几节）。
- 若未来内容为空，显示 `暂无帮助内容`，状态栏仍可 Esc 退出。
- 内容不足一屏时状态栏可显示 `全部显示`，j/k 不改变。

## 8. 可访问性/风格

- 帮助文本使用终端默认前景色；标题用主题强调色/粗体。
- 不使用不可见控制字符；不使用超链接 OSC 8（0.1.3 不做）。
- 状态栏颜色与 List 一致（Info）。
- 帮助打开时隐藏光标（无输入框）。

# 0.1.2 已确认决策

> 只记录已经明确同意的决策；未定项见 [05-open-questions.md](05-open-questions.md)。

## D-001 0.1.2 做点对点文件传递，不做目录同步

- **状态**：已确认（2026-11-19）
- **决策**：用户明确发起 `/send file`，对方明确 `/recv file` 后才传输；不扫描目录、不自动上传、不保持两端一致。
- **影响**：不恢复 0.1.0 的共享目录模型；文件请求/接收是显式命令。

## D-002 `/` 是命令输入入口

- **状态**：已确认
- **决策**：List 层按 `/` 打开 Compose，输入框预填 `/`；Enter 后若以 `/` 开头则按命令解析。
- **影响**：`/` 不是独立模式，仍是 Compose + 命令解析；`i` 仍打开普通消息输入。

## D-003 未知 `/...` 按普通消息发送

- **状态**：已确认
- **决策**：不是已注册命令的内容原样作为聊天消息发送；已注册但参数错误的命令显示用法，不发送。
- **影响**：命令表可以逐步扩展；不会把用户想发的 `/hello` 吞掉。

## D-004 发送/接收命令

- **状态**：已确认
- **决策**：
  - `/send file <本地文件路径> to <对方>`
  - `/recv file <对方>`
- **影响**：一次 `/send` 一个文件；`/recv` 接受该对方全部待接收文件。

## D-005 10 分钟请求超时

- **状态**：已确认
- **决策**：请求从发出起 10 分钟内无人接收则自动取消，双方显示取消提示。
- **影响**：只作用于“等待接收”阶段；接受后的传输超时另定（OQ-12-07）。

## D-006 重复请求拦截

- **状态**：已确认
- **决策**：同一对方 + 同一文件 basename 在 Pending/Transferring 时拒绝重复发送，提示已经发过。
- **影响**：完成后允许重发；不同对方可同名。

## D-007 多文件接收

- **状态**：已确认
- **决策**：同一发送方有多个待接收文件时，`/recv file <对方>` 全部接受。
- **影响**：逐文件传输/结果；一个失败不阻塞其他（建议）。

## D-008 保存目录与重名

- **状态**：已确认
- **决策**：文件保存到 `data_local_dir()/lanchat/files`（Linux 为 `~/.local/share/lanchat/files`）；重名时在文件名后加 `[0]`、`[1]` 自增，不覆盖。
- **影响**：只取 basename；临时文件 + rename；拒绝路径穿越。

## D-009 提示语通俗化

- **状态**：已确认
- **决策**：用户可见提示使用短句、说明下一步、带文件名/来源/最终路径；不显示内部错误码/堆栈。
- **影响**：见 [02-commands.md](02-commands.md) 和 [04-ui.md](04-ui.md) 的文案表。

## D-010 文件请求显示在消息列表的系统消息中

- **状态**：已确认（2026-11-19）
- **决策**：请求/开始/成功/超时用系统消息显示；命令错误/重复/找不到用户用状态栏/toast。
- **影响**：系统消息需要可区分、可复制；是否写历史见 D-013（不写）。

## D-011 文件内容使用独立数据 TCP 连接

- **状态**：已确认
- **决策**：Offer/Accept/Cancel/Timeout 等控制消息走现有 peer 连接；实际文件内容走独立 TCP 数据连接，避免阻塞聊天。
- **影响**：需要数据连接握手/关联 transfer_id；数据端点和生命周期单独设计（复用监听端口，首帧区分用途）。

## D-012 限制：1 GiB / 20 / 100

- **状态**：已确认
- **决策**：单文件上限 1 GiB；每个发送方最多 20 个待接收；全局最多 100 个；数据块 16 KiB。
- **影响**：超限在 `/send` 或 Offer 阶段拒绝并提示。

## D-013 文件系统消息不写历史

- **状态**：已确认
- **决策**：请求/开始/成功/超时等系统消息只在当前运行显示，不写入 JSONL 历史。
- **影响**：重启后不显示过期请求；文件本身仍在 files 目录。

## D-014 对方标识

- **状态**：已确认
- **决策**：支持完整 IP、IP 最后一段（如 101/103）、在线昵称；匹配不到或匹配到多个时提示。
- **影响**：命令解析/错误提示需要处理歧义。

## D-015 重名格式

- **状态**：已确认
- **决策**：`a.png` → `a[0].png` → `a[1].png`；无扩展名 `report` → `report[0]`。
- **影响**：接收端从 `[0]` 开始查找未占用名称。

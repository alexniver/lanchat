# 0.1.0 范围与验收标准

> 状态：核心范围已确认，交互细节以 [08-core-interaction.md](08-core-interaction.md) 为准
> 关联：[open-questions.md](open-questions.md) · [02-keybindings.md](02-keybindings.md) · [03-ui.md](03-ui.md)

## 1. 背景

旧版 lanchat 是一个可运行的局域网聊天 + 文件共享 TUI，但存在结构性问题：

- TUI、状态、网络、文件共享耦合，`AppState` 用 `Arc<Mutex>` 跨任务共享；
- 事件循环用 `event::poll` 阻塞轮询，渲染与输入处理混在一起；
- 消息滚动按“消息条数”而非“显示行”，长消息/换行显示不正确；
- 发送用 `try_send`，通道满时静默丢消息；
- 没有心跳、重连、连接去重和超时，节点掉线后状态容易脏；
- 文件下载整文件 base64 进内存、路径未校验；
- 键位是零散的方向键 + Tab，不是模式化编辑，也不能自定义。

0.1.0 不修补这些代码，而是先按最新需求把**本地聊天核心交互**做对：上下双 panel、信息列表、输入 panel 栈、选中/复制、本地历史、可配置键位。局域网联网移到 0.2。

## 2. 0.1.0 的定义

**0.1.0 = 单机本地聊天验证版：上下双 panel + 输入栈 + 消息选中/复制 + 本地历史 + 可配置键位。**

- 启动后进入上下两个 panel：上为信息列表，下为状态。
- 消息格式：`[name][datetime]: message`。
- 按 `i` 在信息列表下方弹出输入 panel；输入后 Enter 发送并关闭 panel；Esc/空 Enter 关闭且不产生消息。
- 整个 UI 状态用 `Vec<Layer>` 栈表示；`Esc`/`Enter` pop。
- List 模式默认自动选中最后一条；`j/k` 移到非最新 → 手动模式（新消息不自动跳）；移到最新 → 自动模式。
- `y` 复制正文；`Y` 复制完整格式；状态显示“复制成功”。
- Compose 模式选中高亮消失；除 Enter/Esc 外不响应任何应用快捷键（普通字符仍输入）。
- 0.1.0 不联网、无 peer、无文件共享、不伪造在线数；状态显示 `在线 1（本机）`。
- 本地历史 JSONL 持久化；启动加载最近消息。
- 默认键位 Helix-inspired，List 动作可通过 `keymap.toml` 覆盖/解绑。

## 3. 目标

### 3.1 产品目标

- **打开即用**：启动后直接看到信息列表和状态，不需要登录/网络。
- **键盘优先**：所有核心操作可用键位完成，不依赖鼠标。
- **状态清晰**：选中项、消息数、在线数、复制结果都在状态 panel 可见。
- **输入不误触**：输入 panel 打开时，`j/k/y` 等不会触发列表动作。
- **中文可用**：CJK 字符宽度/光标/折行正确；不要求程序加载字体。
- **可回看**：重启后能看到本地历史。
- **可改键**：List 动作可配置；坏配置不锁死。
- **可扩展**：0.2 接网络时复用消息/UI/历史/键位。

### 3.2 成功标准

用户启动 lanchat，看到上下双 panel 和最近消息；按 `i` 出现输入 panel，输入中文，Enter 后消息以 `[name][datetime]: message` 出现在列表并自动选中；Esc 取消输入；`j/k` 移动选中（自动/手动模式切换）；`y` 复制正文、`Y` 复制完整行，状态显示“复制成功”；`Q` 退出后终端恢复；重启能看到历史。

## 6. 功能需求

### FR-01 启动与退出

- `[必须]` 启动后进入 alternate screen + raw mode，显示上下双 panel。
- `[必须]` 启动时加载配置、身份、历史；失败时给出可读错误而不是 panic。
- `[必须]` 首次启动显示一行提示：`i` 输入、`j/k` 选择、`y/Y` 复制、`Q` 退出。
- `[必须]` 退出键：`Q`（List 层，已确认）；Compose 下 `Q` 是普通字符；退出时恢复终端、flush 历史。
- `[必须]` 退出、panic 时恢复终端（raw mode、alternate screen、光标、paste）。
- `[必须]` 退出时 flush 历史，不丢最后几条消息。

### FR-02 布局与状态 panel

- `[必须]` 上下两个 panel：上信息列表占剩余高度；下状态 panel 固定 **3 行**（建议）。
- `[必须]` 状态 panel 显示：`在线 1（本机） · 消息 N · 选中 i/N · 自动/手动`。
- `[必须]` 复制成功时状态追加 ` · 复制成功`，2 秒后消失；失败显示 ` · 复制失败`。
- `[必须]` 输入 panel 显示时，状态显示 `输入中 · Enter 发送 · Esc 取消`。
- `[应该]` 状态栏文字按显示宽度截断，不按字节截断。
- `[必须]` 0.1.0 不显示真实 peer/连接状态；`在线 1（本机）` 不伪造其他节点。

### FR-03 信息列表

- `[必须]` 消息格式严格为 `[name][datetime]: message`。
- `[必须]` `datetime` 为 `YYYY-MM-DD HH:MM:SS`（本地时间，已确认）。
- `[必须]` 长消息按终端宽度折行；逻辑上仍是一条消息；选中高亮覆盖所有续行。
- `[必须]` 启动默认自动模式，选中最后一条；无消息时无选中。
- `[必须]` 自动模式下，新消息（含自己发送）自动选中最新并滚动到底。
- `[必须]` 用户 `j/k` 选中非最新 → 手动模式；手动模式下新消息不改变选中/滚动。
- `[必须]` 用户 `j/k` 选回最新 → 自动模式恢复。
- `[必须]` `j` 下移、`k` 上移；到顶/到底 clamp，不循环。
- `[必须]` 选中项始终可见；滚动按显示行，移动按消息条。
- `[必须]` 无消息时无选中；`j/k` 无动作；`y/Y` 提示无消息或忽略。

### FR-04 选中与复制

- `[必须]` `y` 复制当前消息正文 `message`。
- `[必须]` `Y` 复制完整格式 `[name][datetime]: message`。
- `[必须]` 复制成功状态栏显示“复制成功”，2 秒后消失。
- `[必须]` 复制失败显示“复制失败”，不崩溃。
- `[应该]` 本地优先系统剪贴板（`arboard`），SSH/远程尝试 OSC 52 兜底（OQ-29）。
- `[必须]` 复制内容与显示内容一致（`Y` 的完整行不带折行/高亮）。

### FR-05 输入 panel 与 stack

- `[必须]` List 模式按 `i`：`layers.push(Compose)`，在信息列表下方显示输入 panel；选中高亮消失。
- `[必须]` Compose 模式：
  - 只响应 `Enter`/`Esc` 两个应用快捷键；
  - 普通字符（含 `i/j/k/y/Y`）作为文本输入；
  - 方向键/Home/End/Backspace/Delete 由输入框处理；
  - `Ctrl+C` 不作为应用快捷键；`Q`/`q` 作为普通字符输入，不退出。
- `[必须]` Compose 下 `Esc`：pop，丢弃输入，不产生消息。
- `[必须]` Compose 下空/纯空白 `Enter`：pop，不产生消息。
- `[必须]` Compose 下非空 `Enter`：追加消息（当前 name/datetime/body），pop；自动模式选中新消息，手动模式保持原选中（OQ-31）。
- `[必须]` 基础 `List` 永不 pop；`Esc`/`Enter` 在 List 下不退出/不发送。
- `[必须]` 输入 panel 固定 3 行（建议）；关闭后信息列表恢复高度。
- `[必须]` 取消输入后恢复打开前的选中（OQ-28）；发送时按自动/手动模式决定选中。
- `[必须]` 整个 UI 状态用 `Vec<Layer>` 栈；`Esc`/`Enter` pop；键位分发只看栈顶。

### FR-06 输入编辑与中文

- `[必须]` 单行输入；支持 UTF-8/中文/emoji；光标/删除按字符边界。
- `[必须]` 水平滚动，光标始终可见；按显示宽度计算光标位置。
- `[必须]` 粘贴：换行转空格；过滤控制字符。
- `[必须]` 空白消息不发送；单条消息上限 16 KiB，超限提示。
- `[必须]` 终端未使用 CJK 等宽字体时，不 panic；可能显示 tofu/错位，文档说明。
- `[必须]` 不加载字体；字体由终端提供（见 08 文档）。

### FR-07 本地历史

- `[必须]` 消息追加写入本地 JSONL；启动加载最近 N 条（OQ-19）。
- `[必须]` 历史保存 name/datetime/body；加载后按原格式显示。
- `[必须]` 历史文件权限 `0600`；不写聊天正文到 tracing 日志。
- `[必须]` 文件损坏时跳过坏行并继续启动，保留错误提示。
- `[必须]` 历史按日期/大小轮转，限制总占用。
- `[必须]` 退出时 flush；不丢最后几条消息。
- `[不做]` 多端同步（0.2 也不做）。

### FR-08 可自定义键位

- `[必须]` 内置默认键位：List `i/j/k/y/Y/Q`、Compose `Enter/Esc`。
- `[必须]` 用户可通过 `~/.config/lanchat/keymap.toml` 覆盖/解绑 List 动作。
- `[必须]` 支持多键序列、`Ctrl` 组合、方向键/功能键名（为后续扩展）。
- `[必须]` 动作注册表稳定（`open_compose`、`cursor_down`、`cursor_up`、`copy_body`、`copy_line`、`quit` 等）。
- `[必须]` 合并规则：默认 + 用户覆盖；`"none"` 解绑；冲突检测。
- `[必须]` 保留键：Compose 的 `Enter`/`Esc`、List 的 `Q` 不可重映射（已确认）。
- `[必须]` 坏配置不锁死：回退默认并提示；`--no-config` 跳过用户配置。
- `[必须]` 启动时加载 keymap；0.1.0 可要求改键后重启生效；热重载 `:keymap reload` 为 P2（需要命令层，见 OQ-17）。
- `[应该]` 配置错误报告具体键/动作。

### FR-09 状态与错误

- `[必须]` IO/配置/历史/剪贴板错误转成状态栏提示或 toast，不 panic。
- `[必须]` 历史写入失败可见；不静默丢消息。
- `[必须]` 日志包含错误上下文，但不含聊天正文。
- `[应该]` `--debug` / `LANCHAT_LOG` 调整日志级别。

### FR-10 配置

- `[必须]` 配置文件路径遵循 XDG（Linux）：`~/.config/lanchat/config.toml`；数据：`~/.local/share/lanchat/`；状态/日志：`~/.local/state/lanchat/`。
- `[必须]` `config.toml` 包含昵称、历史开关/上限、UI 选项；未知字段忽略并警告。
- `[必须]` `keymap.toml` 独立；`--no-config` 跳过用户配置。
- `[应该]` 命令行参数：`--config`、`--keymap`、`--no-config`、`--version`、`--help`。
- `[不做]` 主题自定义、图形化键位编辑器（0.2+）。

### FR-11 单机边界

- `[必须]` 不模拟 peer、不造假在线数、不显示成员列表。
- `[必须]` 状态栏显示 `在线 1（本机）`；不显示“连接中/在线 peer”。
- `[必须]` 0.1.0 不引入 `mdns-sd`/socket/网络协议依赖。
- `[应该]` 0.2 的网络字段在消息模型中预留（`from`、`room`），但 0.1.0 只写入本机。

### FR-12 可选增强（P2，不阻塞 0.1.0）

- 搜索、命令模式、帮助/which-key、`x/v/y` 范围选择、主题、`x` 复制多选。
- 这些功能如果实现，必须遵守 stack：新层压栈，`Esc`/`Enter` pop；Compose 下仍只响应 Enter/Esc。

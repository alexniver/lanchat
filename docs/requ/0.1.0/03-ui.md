# 界面与交互

> 状态：草案；0.1.0 核心交互以 [08-core-interaction.md](08-core-interaction.md) 为准
> 关联：[02-keybindings.md](02-keybindings.md) · [01-scope.md](01-scope.md)

## 1. 布局原则

- **上下双 panel**：上方信息列表，下方状态；输入 panel 按需插入两者之间。
- **状态常驻**：状态 panel 始终可见，显示在线数、消息数、选中位置、临时提示。
- **键盘优先**：不依赖鼠标。
- **单机不装联网**：不显示真实 peer/连接状态；状态显示 `在线 1（本机）`。
- **中文友好**：CJK 用显示宽度计算；程序不加载字体，终端需 CJK 等宽字体。
- **不靠颜色单独表达状态**：选中用高亮 + 标记；复制成功/失败有文字。

## 2. 主界面（List 层）

```text
┌ 信息列表 ──────────────────────────────────────────────────────┐
│ [alice@arch][2026-11-19 10:30:01]: 你好                         │
│ [alice@arch][2026-11-19 10:30:05]: 在                           │
│ [alice@arch][2026-11-19 10:31:12]: 今天先到这里                 │
│                                                                 │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
┌ 状态 ──────────────────────────────────────────────────────────┐
│ 在线 1（本机） · 消息 3 · 选中 3/3 · 自动              │
└─────────────────────────────────────────────────────────────────┘
```

- 上 panel 占剩余高度；下 panel 固定 3 行（建议）。
- 信息列表带边框；状态 panel 带边框。
- 选中项整条高亮（含折行续行）；左侧可用 `▌` 标记。
- 启动默认自动模式，选中最后一条；没有消息时无选中。
- 自动模式下新消息自动选中最新；手动模式下新消息不自动跳（见 3.2）。

### 2.1 状态 panel 高度

**建议 3 行**：

```text
┌ 状态 ──────────────────────────────────────────┐
│ 在线 1（本机） · 消息 3 · 选中 3/3 · 自动 │
└────────────────────────────────────────────────┘
```

- 终端单元格高度 = 一行文字；3 行 = 1 行内容 + 上下边框，比一行文字略高。
- 不用边框时可 2 行（1 行内容 + 1 行分隔），但 0.1.0 推荐 3 行带边框。
- 状态内容放不下时按显示宽度截断/省略，不能按字节截断。

## 3. 信息列表

### 3.1 消息格式

严格为：

```text
[name][datetime]: message
```

示例：

```text
[alice@arch][2026-11-19 10:30:01]: 你好
[alice@arch][2026-11-19 10:30:05]: 在
```

- `name`：本机昵称，默认 `username@hostname`。
- `datetime`：本地时间，`YYYY-MM-DD HH:MM:SS`（已确认）。
- 长消息按终端宽度折行；逻辑上一条消息；选中高亮覆盖所有续行。
- 续行不重复 `[name][datetime]`，缩进显示（建议）。

### 3.2 选中模式与滚动

List 层有两种选择模式：

| 模式 | 进入 | 新消息到达 |
| --- | --- | --- |
| 自动 | 默认；选中的是最后一条 | 自动选中最新并滚动到底 |
| 手动 | `j/k` 选中了非最新消息 | 不改变选中/滚动；消息数增加 |

- 启动默认自动，选中最后一条。
- `j/k` 后：选到最新 → 自动；选到非最新 → 手动。
- 手动模式下，新消息（含自己发送）不自动选中；用户 `j` 到最新后恢复自动。
- `j` 下移、`k` 上移；到顶/到底 clamp，不循环。
- 选中项必须可见；移动时自动滚动；滚动按显示行，`j/k` 按消息条。
- 状态 panel 显示 `自动`/`手动`。
- 无消息时：无选中；`j/k` 无动作；`y/Y` 提示或忽略。
- 复制成功：状态追加 ` · 复制成功`，2 秒后消失；失败 ` · 复制失败`。

## 4. 输入 panel（Compose 层）

按 `i` 后，在信息列表和状态 panel 之间插入输入 panel：

```text
┌ 信息列表 ──────────────────────────────────────────────────────┐
│ [alice@arch][2026-11-19 10:30:01]: 你好                         │
│ [alice@arch][2026-11-19 10:30:05]: 在                           │
│                                                                 │
├ 输入 ──────────────────────────────────────────────────────────┤
│ > 你好▌                                                         │
└─────────────────────────────────────────────────────────────────┘
┌ 状态 ──────────────────────────────────────────────────────────┐
│ 输入中 · Enter 发送 · Esc 取消 · 消息 2                        │
└─────────────────────────────────────────────────────────────────┘
```

- 输入 panel 固定 3 行（上边框 + 1 行输入 + 下边框）。
- 输入 panel 出现时，信息列表高度减少；列表仍可见。
- **选中高亮消失**；列表不响应 `j/k/y/Y/i` 等应用快捷键。
- Compose 下只有 `Enter`/`Esc` 两个应用快捷键；其他字符进入输入框。
- Enter 非空：消息追加、panel 消失；自动模式选新消息，手动模式保持原选中。
- Enter 空/纯空白：panel 消失，不产生消息。
- Esc：panel 消失，丢弃输入，不产生消息。
- 输入框单行；支持中文/emoji；水平滚动；光标可见。
- 输入 panel 消失后，列表恢复高度；发送按自动/手动模式决定选中，取消恢复原选中。

## 5. 状态 panel 内容

```text
在线 1（本机） · 消息 3 · 选中 3/3 · 自动
```

| 字段 | 说明 |
| --- | --- |
| `在线 1（本机）` | 0.1.0 固定；0.2 显示真实 peer 数 |
| `消息 N` | 当前列表中消息数 |
| `选中 i/N` | 第 i 条 / 总数；无消息 `选中 -/-` |
| `自动` / `手动` | 当前选择模式 |
| 临时提示 | `复制成功`/`复制失败`/`已发送`，2 秒后消失 |
| 输入提示 | `输入中 · Enter 发送 · Esc 取消` |

- 状态文字颜色：普通灰/白，错误红，成功绿；同时有文字。
- 时钟/日期可选放在状态右侧；0.1.0 可省略。

## 6. 颜色与主题

默认 16 色安全主题：

| 元素 | 颜色/样式 |
| --- | --- |
| 背景/正文 | 终端默认 |
| 选中项 | 背景 DarkGray/Cyan + `▌` |
| 时间/name | 默认或 Cyan |
| 复制成功 | Green `✓` |
| 复制失败/错误 | Red `!` |
| 输入光标 | 反色/`▌` |
| 状态 panel | DarkGray 文本 |

- 支持 `NO_COLOR`：关闭颜色，仍用文字/符号。
- 不以颜色作为唯一信息载体。
- 主题切换 0.2+。

## 7. 中文与字体

**程序不加载字体。** 终端字体由终端模拟器提供；程序只输出 UTF-8 + ANSI。

要求：

1. 终端使用支持 CJK 的**等宽字体**：Sarasa Mono SC、Noto Sans Mono CJK SC、Maple Mono NF CN、更纱黑体等；或西文等宽字体 + CJK fallback。
2. locale/编码为 UTF-8。
3. 程序用 `unicode-width`：中文/全角 2 列，ASCII 1 列；光标/折行/截断按显示宽度。
4. 输入法候选框由终端处理；0.1.0 不做自定义 IME UI。
5. 字体缺字会显示 tofu（□），属于终端字体问题；帮助/README 说明推荐字体。

> 结论：不需要在 Rust 里加载字体；需要用户在终端里配置 CJK 等宽字体。若不做，中文可能错位/显示方块。

## 8. 终端行为

- 进入 alternate screen + raw mode；退出/panic 恢复。
- 启用 bracketed paste；关闭鼠标捕获。
- 光标：Compose 下显示；List 下隐藏（用高亮/`▌` 指示选中）。
- 最小尺寸 60×15：
  - 小于最小尺寸时显示 `终端太小（至少 60×15）`；
  - resize 后恢复。
- 尺寸变化时重新折行；尽量保持选中项可见。
- 挂起/恢复（`Ctrl+Z`、`fg`）0.1.0 不做；使用 `Q` 退出。
- 远程/SSH：OSC 52 复制可用；本地剪贴板不保证。

## 9. 启动与关闭

### 启动

1. 解析 CLI/配置；失败时打印错误并退出（非 raw mode）。
2. 初始化日志/panic hook。
3. 加载身份、键位、历史。
4. 进入 alternate screen + raw mode。
5. 渲染双 panel；默认选中最后一条；首次启动显示提示行。
6. 0.1.0 不启动网络。

### 关闭

1. `Q`（List 层，已确认）→ flush 历史 → 恢复终端 → 退出。
2. `Esc`/`Enter` 只 pop 层；不会退出。
3. panic → panic hook 恢复终端并写日志。
4. 所有退出路径共用 `TerminalGuard::drop`。

## 10. 可选增强（不阻塞 0.1.0）

- 搜索、命令、帮助/which-key。
- 多选/范围复制。
- 主题、时钟、日期分隔线。
- 这些功能必须继续压栈；`Esc`/`Enter` pop；Compose 下仍只响应 Enter/Esc。

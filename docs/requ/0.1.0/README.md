# lanchat 0.1.0 需求讨论

> 状态：**讨论中，核心范围已确认**
> 建立日期：2026-11-19
> 实现状态：0.1.0 核心已实现（单机版），见根目录 README
> 旧实现：`old/`，不参与编译，仅作参考

## 一句话目标

一个 **Helix-inspired、键位可自定义** 的终端聊天工具：0.1.0 先交付单机上下双 panel、输入栈、选中/复制、本地历史与键位配置，0.2 再接局域网。

## 已确认的 0.1.0 范围

| 能力 | 0.1.0 | 说明 |
| --- | --- | --- |
| 上下双 panel | ✅ 做 | 上：信息列表；下：状态（建议 3 行） |
| 单机聊天 | ✅ 做 | 单进程、本地消息；格式 `[name][datetime]: message` |
| 输入 panel + stack | ✅ 做 | `i` 压入 Compose；`Esc`/`Enter` pop；`Q` 退出 |
| 选中与复制 | ✅ 做 | 默认自动选最新；`j/k` 移动并切换自动/手动；`y`/`Y` 复制；状态“复制成功” |
| 本地历史 | ✅ 做 | JSONL 持久化，启动加载最近消息 |
| 可自定义键位 | ✅ 做 | 默认 Helix-inspired；List 动作可覆盖/解绑 |
| 搜索 / 命令 / 帮助 | 🟡 可选 | 核心验收不包含；时间允许再加 |
| 文件共享 | ❌ 不做 | 从 0.1.0 删除 |
| 局域网联网 | ❌ 0.1.0 不做 | mDNS/TCP/peer/重连整体移到 0.2 |
| 多频道 / 私聊 | ❌ 不做 | 后续版本 |
| 加密 / 鉴权 | ❌ 0.1.0 不做 | 0.2 联网时再定义边界 |
| 鼠标 | ❌ 不做 | 键盘优先 |
| 多行输入 | ❌ 0.1.0 不做 | Enter 发送；多行放 0.2 |

> 0.1.0 的“聊天”是单机版：先按 [08-core-interaction.md](08-core-interaction.md) 的上下双 panel、输入栈、选中/复制流程做本地验证；0.2 再让消息跨机器。

## 讨论流程

1. 未定项统一记录在 [`open-questions.md`](open-questions.md)，每项给出选项和推荐。
2. 用户确认后，在 [`decisions.md`](decisions.md) 记录决策，并同步修改对应文档。
3. 需求冻结后，[01-scope.md](01-scope.md) 的验收标准作为“0.1.0 完成”的判定依据。
4. 实现阶段发现的遗漏，先回到本目录补需求，再改代码，避免边写边改需求。

## 旧代码的处理

0.1.0 之前的实现已整体移动到 [`old/`](../../../old/)：

- `old/src/`：旧 TUI、网络、文件共享实现；
- `old/SPEC.md`、`old/README.md`：旧版设计文档；
- `old/Cargo.toml`、`old/Cargo.lock`：旧依赖，便于对照；

`old/` 已被根 `Cargo.toml` 的 `[workspace] exclude` 排除，**不参与根项目编译**。旧代码只用于参考，不直接复用；新实现从零开始。

## 术语

| 术语 | 含义 |
| --- | --- |
| 本地聊天 | 0.1.0 的单进程聊天：消息只在本机产生和显示 |
| 房间 / room | 0.1.0 中只有一个 `#lobby` |
| List / Compose | 两层 UI 栈：信息列表层 / 输入层 |
| 消息游标 | List 层当前选中的消息，`j/k` 移动 |
| 自动 / 手动 | List 层的选中模式；手动下新消息不自动跳 |
| 显示行 | 消息按终端宽度折行后的行；滚动以显示行为单位 |
| action | 键位映射的目标，如 `cursor_down`、`copy_body`、`open_compose` |
| effect | 由状态更新产生、需要运行时执行的动作（保存历史、退出等） |

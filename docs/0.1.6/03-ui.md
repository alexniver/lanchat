# 界面

> 状态：已实现

## 消息列表

```text
[alice (no1)][2026-11-19 10:30:01]: 你好
[bob (no2)][2026-11-19 10:30:05]: 在
```

- 本地/远端消息都使用 display name。
- `Y` 复制完整行包含 `(no1)`。
- 历史保存 display name。
- 老 peer 显示 `(node8)`，没有短号。

## 成员栏

```text
● alice (no1)
  (you) · 本机
● bob (no2)
  192.168.1.103:47731
```

- 自己保留 `(you)`。
- 地址行仍是 `IP:port`。
- 短号更新后成员栏立即更新。

## 文件提示

```text
alice (no1) 想发送文件 a.png（1.2 MB）。输入 /recv file no1 接收。
```

- `no1` 对应短号。
- IP 目标提示显示 `ip101`（如果用户用 IP 发起）。
- 失败/成功/取消提示使用 display name。

## 边界

- 短号 0/老 peer：node8 回退。
- 基础名空：`用户 (no1)`。
- 短号冲突顺延：显示新 no；旧消息不改。
- 短号复用：历史中 no 可能对应不同节点；`from` node_id 仍是准确来源。

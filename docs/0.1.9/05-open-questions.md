# 0.1.9 已确认决策

> 状态：需求已确认，待实现

## 已确认

| 项目 | 结论 |
| --- | --- |
| 接收命令 | `/recvfolder <对方>`，兼容 `/recv folder <对方>` |
| 目录结构 | 保留 |
| 空目录 | 保留 |
| 符号链接 | 默认跳过 |
| 发送限制 | 取消单文件/文件夹大小、文件数、深度限制 |
| 接收磁盘检查 | 剩余空间 ≥ 剩余待传数据 × 1.5，否则双方失败 |
| 文件夹失败 | 整体失败，清理临时目录 |
| 状态提示 | 只在 List 层最右显示 `[?]帮助` |
| 状态键位 | 跟随 keymap 的 `open_help`；未绑定隐藏 |

## 仍待实现时确认

- 磁盘空间 API 的具体实现（Unix/Windows）。
- 文件夹 manifest 的分块大小。
- 文件夹进度显示（P1）。
- `/recv folder` 是否也接受单文件（当前不做）。
- 是否保留请求数量限制（安全边界，建议保留）。

## 不做

- 文件夹同步/监听。
- 压缩传输。
- 断点续传。
- 跟随符号链接。
- 自动接收。
- 多选文件夹。

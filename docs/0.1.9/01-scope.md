# 0.1.9 范围与验收

> 状态：讨论中

## 目标

- `/sendfolder <目录> to <对方>` 递归发送。
- `/recvfolder <对方>` 接收该发送方全部待接收文件夹；兼容 `/recv folder <对方>`。
- 保留相对目录结构和空目录。
- 文件夹根目录重名自动 `[0]`/`[1]`。
- 复用 10 分钟超时、重复请求拦截、独立数据连接。
- 文件夹失败整体失败，不保留半成品。
- 状态栏最右显示 `[?]帮助`。

## 非目标

| 不做 | 说明 |
| --- | --- |
| 文件夹同步 | 仍是一次性传递，不监听变化 |
| 压缩/打包 | 目录按原结构传 |
| 断点续传 | 0.1.9 不做 |
| 跟随符号链接 | 默认跳过 |
| 保留权限/所有者/时间戳 | 仅内容/结构 |
| 自动接收 | 必须 `/recvfolder` |
| 文件夹搜索/预览 | 不做 |
| 多选文件夹 | 一次一个 `/sendfolder` |
| 帮助提示在 Compose/Members/Help | 只在 List |

## 规则

### 发送

- 路径必须是目录；文件用 `/sendfile`。
- 递归扫描，相对路径保留。
- 空目录也要记录。
- 默认跳过符号链接，并在提示中说明。
- 跳过不可读文件/目录时：建议直接失败并提示，避免“静默少文件”。
- 取消发送端的单文件/文件夹大小、文件数、深度限制。
- 接收端在接受前检查磁盘剩余空间：必须不少于剩余待传数据的 1.5 倍。

### 接收

- `/recvfolder no1` 接收该发送方全部待接收文件夹。
- 保存到 `<files_dir>/<root>/...`。
- 根目录重名：`root[0]`、`root[1]`。
- 内部相对路径逐段 sanitize；拒绝 `..`、绝对路径、路径穿越。
- 先写临时目录，全部完成后 rename；失败清理临时目录（建议）。
- 空目录创建。

### 超时/重复

- 请求 10 分钟未接收自动取消。
- 同一发送方 + 根目录名未完成时拦截重复请求。
- 接受后请求超时停止；数据阶段沿用空闲超时。

### 状态栏提示

- 只在 List 层显示 `[?]帮助`。
- 最右侧、单行、不换行。
- 宽度不足时先隐藏提示。
- keymap 改键后显示当前 `open_help` 键位；未绑定隐藏。

## 验收

- [ ] `/sendfolder ~/dir to no1`，接收方看到文件夹请求。
- [ ] `/recvfolder` 和 `/recv folder` 都能接收；目录结构/空目录正确。
- [ ] 根目录重名 `dir[0]`。
- [ ] 10 分钟未接收取消。
- [ ] 接收端磁盘不足时双方看到失败提示。
- [ ] 同根目录重复请求拦截。
- [ ] 符号链接被跳过且提示。
- [ ] 路径穿越被拒绝。
- [ ] List 状态栏最右 `[?]帮助`。
- [ ] Compose/Members/Help 不显示该提示。
- [ ] 0.1.8 的 118 个测试回归；当前 118。

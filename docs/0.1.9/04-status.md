# 状态栏 `[?]帮助`

> 状态：已实现

## 目标

在消息列表底部状态栏**最右侧**显示：

```text
[?]帮助
```

完整示例：

```text
本机 alice (no1) · 在线 2 · 消息 3 · 选中 3/3 · 自动 · ● online        [?]帮助
```

## 显示范围

| 层 | 是否显示 | 原因 |
| --- | --- | --- |
| List | ✅ | `?` 是帮助入口（已确认） |
| Compose | ❌ | `?` 是普通字符（已确认） |
| Members | ❌ | `?` 被忽略（已确认） |
| Help | ❌ | 已在帮助页，Esc 退出（已确认） |

## 对齐

- 状态栏内容一行：左侧状态、右侧提示。
- 右侧固定到 panel 内宽最右边。
- 左侧内容过长时截断；右侧优先保留。
- 总宽度不足时隐藏 `[?]帮助`，不换行。
- 右侧提示用 Info/Muted 样式。

## 动态键位

- 使用当前 keymap 的 `open_help` 键：
  - 默认：`[?]帮助`
  - 改键：`[g]帮助`
  - 未绑定：隐藏
- 多键序列（如 `Space h`）可显示 `[Space h]帮助`；太宽时截断/隐藏。
- 文案保持 `[<键>]帮助`。

## 实现建议

- `status_text` 拆成 `left` / `right`；
- `ui/status.rs` 用 `Line` 拼左右，按 `unicode-width` 计算填充；
- 右侧宽度 = 显示宽度(`[?]帮助`)；
- 左侧最大宽度 = inner.width - right_width - 1；
- 若 `inner.width < right_width + 8`，只显示左侧。
- 测试：默认键、改键、未绑定、窄终端、中文宽度。
